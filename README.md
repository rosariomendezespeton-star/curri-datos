
# 📊 Análisis de Datos Agroindustriales - Campaña Curri Huelva

Este repositorio contiene el proyecto práctico de análisis de datos enfocado en la optimización de procesos agrícolas y logísticos en la provincia de Huelva.

## 🎯 Objetivos del Proyecto
* **Analizar el rendimiento** de producción por tipo de cultivo (mandarinas, olivos y almendros).
* **Evaluar la eficiencia del uso de agua** e impacto de variables climáticas en el rendimiento.
* **Identificar patrones de distribución** y cuellos de botella en la cadena logística hacia Europa.

## 🛠️ Herramientas y Tecnologías
* **Python / Pandas:** Procesamiento y limpieza de datos.
* **Matplotlib / Seaborn:** Visualización de datos y patrones.
* **SQL:** Consultas a bases de datos relacionales de producción.
* **Git / GitHub:** Control de versiones y documentación.
